# NOCTURNE: 불시착 — 개발 회의록 (1~9차)

> ⚠ 이 회의록은 **가상 인물들의 역할극**입니다. 실제 사람이 플레이한 결과가 아니라, 첫 빌드를 직접 테스트하면서 확인한 약점을 바탕으로 각 입장에서 토론한 내용입니다. 회의에서 ✅ 표시된 결정은 실제로 게임 코드에 반영되었습니다.

**참석자**

| 이름 | 역할 | 관점 |
|------|------|------|
| 은겸 | 게임 개발자 (7년차, 시니어) | 구현 비용, 네트워크, 유지보수 |
| 하은 | 디자이너 (5년차) | 레벨/UX/비주얼, 플레이 경험 설계 |
| 하나 | 플레이 테스터 (20대) | 스토리·분위기를 즐기는 캐주얼 플레이어 |
| 두리 | 플레이 테스터 (20대) | 효율·공략형, 지루함에 민감 |
| 삼식 | 플레이 테스터 (20대) | 친구들과 멀티 위주, 디스코드 없이 하는 경우 많음 |

## 1차 회의 — 첫 빌드 플레이 리뷰 (킥오프)

**안건:** 첫 빌드(미션 11개, 1~4인 링크 멀티)를 한 판씩 해보고 문제점 모으기

- **하나:** 조종실 바닥에서 눈 깜빡이며 깨어나는 장면, 빨간 비상등은 진짜 좋았어요. 근데 손이 화면을 너무 많이 가려요. 장갑이 거의 화면 1/3이에요.
- **두리:** 미션 5에서 방어등 세우고 나면 미션 6이 "밤 버티기"인데… 방어등 안에 서서 4~5분 동안 아무것도 안 했어요. 핸드폰 보다가 끝남.
- **삼식:** 친구랑 했는데 디스코드 없이 하니까 "저기 빛나는 거"를 설명을 못 해요. 채팅 치는 동안 외계인한테 잡히고.
- **하은:** 밤이 너무 까매요. 무서운 게 아니라 지형이 아예 안 보여서 답답한 쪽이에요. 공포는 "보일 듯 말 듯"이어야 해요.
- **두리:** 휴대폰 검색은 아이디어 좋은데, 처음엔 뭘 쳐야 할지 몰라서 막혔어요.
- **은겸:** 구조 설명부터 할게요. 방장 브라우저가 서버 역할(`host.js`)을 하고, 미션·아이템·검색 사전은 전부 `data.js`의 데이터라서 수정 비용은 낮아요. 오늘 나온 걸 우선순위로 나눠서 다음 회의부터 하나씩 처리하죠.

**결정 사항**
1. 이슈 목록 확정: ① 첫 밤이 지루함 ② 음성 없이 소통 불가 ③ 밤 가시성 ④ 검색 진입 장벽 ⑤ 공용 가방이라 대원별 개성이 없음 ⑥ 손 크기
2. ⑥ 손 크기는 즉시 수정 ✅ (손 위치를 더 멀리·아래로)

## 2차 회의 — 협동 설계: 역할과 소통

**안건:** 이슈 ②(소통), ⑤(대원별 개성)

- **삼식:** 제일 급한 건 "여기!" 찍는 거요. 에이펙스 핑처럼.
- **은겸:** 핑은 싸요. Q나 우클릭 → 바라보는 지형 지점 계산 → 방장이 전원에게 뿌림. 화면엔 빛 기둥 + 나침반 📍. 연타 방지로 1인당 0.8초 제한 걸게요.
- **하은:** 기둥 색은 각자 대원 색으로 해야 누가 찍었는지 보여요. 12초 뒤 사라지게.
- **두리:** 공용 가방이라 다 같이 같은 걸 줍고 있어요. 각자 할 일이 없음.
- **하은:** 역할을 나누죠. 정찰병 / 엔지니어 / 의무병.
- **삼식:** 역할 고정은 싫어요. 넷이 다 정찰병 하고 싶을 수도 있잖아요.
- **은겸:** 그럼 로비에서 자유 선택, 중복 허용으로. 그리고 효과는 **숫자만 바꾸는 패시브**로 가요. 전용 스킬을 만들면 밸런스 지옥이 열려요.
- **두리:** 엔지니어가 채집 빠르면 다들 엔지니어만 하지 않을까요?
- **하은:** 정찰병은 외계인한테 덜 들키는 게 핵심이라 밤 미션(결정 채굴, 안테나 엄호)에서 확실히 필요해요. 의무병은 4인에서 빛나고요.

**결정 사항** ✅ 전부 구현
| 역할 | 효과 |
|------|------|
| 🏃 정찰병 | 달리기 속도 +8%, 스태미나 소모 -40%, 외계 생물 감지 범위 -4m |
| 🔧 엔지니어 | 채집·채굴 시간 ×0.55, 주파수 튜닝 판정 관대 |
| ⛑️ 의무병 | 쓰러진 동료 부축 2.5초 → 0.8초 |

- 핑: **Q / 우클릭**, 대원 색 빛 기둥 12초 + 나침반 📍 + 효과음 ✅

## 3차 회의 — 페이싱: "첫 번째 밤"을 살리기

**안건:** 이슈 ①, 그리고 플레이 시간 2시간 목표

- **두리:** 밤 4~5분이 그냥 대기예요. 이게 제일 큰 문제.
- **하은:** 밤에 "지켜야 할 것"이 있어야 해요. 방어등 배터리가 닳게 하고, 기둥에서 발전기 크랭크를 돌려야 유지되게 하면 어때요?
- **은겸:** 구현은 간단해요. 밤 동안 75초에 걸쳐 0이 되고, E를 길게 누르면 혼자 5초, 둘이면 2.5초에 가득. 낮에는 태양광으로 자동 충전. 30%와 0%에 MIRA 경고.
- **하나:** 꺼지면 바로 죽어요? 그건 너무 하드한데…
- **은겸:** 즉사는 아니고, 보호막만 꺼져서 외계 생물이 들어올 수 있게 돼요. 빛도 약해지면서 깜빡이게 하면 "곧 꺼진다"는 걸 눈으로 알 수 있고요.
- **삼식:** 그럼 둘이면 한 명은 돌리고 한 명은 조명탄 들고 망보는 그림이 나오겠네요.
- **두리:** 플레이 시간은요? 2시간이 목표였잖아요.
- **은겸:** 지금 구조로 추정하면 75~90분이에요. 숫자는 실제 사람 플레이로 재야 해요. 2시간을 채우는 건 **밤을 늘리는 게 아니라 새 이벤트**로 가야 지루하지 않아요.

**결정 사항**
- ✅ 방어등 배터리 + 크랭크 발전기 (HUD에 배터리 바, 30%↓ 주황, 0% 깜빡임)
- ✅ 첫 밤 목표 문구에 "방어등 발전기를 계속 돌려야 함" 명시, MIRA 안내 대사 추가
- 📋 백로그: 낮 동안 랜덤 이벤트(포자 폭풍), 실제 플레이 시간 측정

## 4차 회의 — 아트 & UX 정리

**안건:** 이슈 ③(밤 가시성), ④(검색 진입 장벽), 기타 화면 문제

- **하은:** 밤 조명 수치를 조정했어요. 하늘빛 최소값 0.2 → 0.34, 달빛 0.35 → 0.6, 밤 안개 농도는 30% 줄였어요. 이제 지형 윤곽은 보이고 먼 곳은 어두워요.
- **하나:** 손전등 켰을 때 외계인 몸이 금속처럼 번쩍여서 덜 무서웠어요.
- **하은:** 피부를 무광 검정으로 바꿨어요. 붉은 눈만 보이는 게 더 무서워요. ✅
- **두리:** 검색은 그냥 정답 버튼을 주면 안 돼요?
- **하은:** 그럼 "폰으로 찾아서 만든다"는 이 게임의 재미가 사라져요.
- **두리:** 근데 막히면 그냥 꺼요, 저는.
- **은겸:** 타협안: 검색 화면에 **지금 미션의 힌트 단어만** 칩 버튼으로 보여주기. 결과를 읽고 재료를 찾아다니는 건 여전히 플레이어 몫이고요.
- **삼식:** 나침반 위에 목표 이름이 겹쳐서 안 읽혀요.
- **은겸:** 그건 이미 고쳤어요. 가까운 라벨끼리는 하나만 표시돼요. ✅

**결정 사항**
- ✅ 밤 가시성 조정, 외계 생물 무광 처리, 나침반 라벨 겹침 해결
- ✅ 검색 앱: 추천 검색어 칩 (현재 미션 힌트 기준)

## 5차 회의 — 구현 리뷰 & 2차 플레이 테스트

**안건:** 2~4차 결정사항이 실제로 들어간 빌드 확인

- **삼식:** 핑 진짜 편해요. 친구가 버섯 숲에서 주황 기둥 찍어주니까 바로 감. 이거 없었으면 어떻게 했나 싶어요.
- **두리:** 첫 밤이 완전 달라졌어요. 배터리 30% 경고 뜨고 빛이 깜빡이니까 진짜 급해져요. 저는 크랭크, 친구는 조명탄 들고 문 앞에 서 있었어요.
- **하나:** 저는 의무병 했는데 1초 부축이 너무 사기 아니에요? 쓰러져도 무섭지가 않아요.
- **은겸:** 의무병이 없으면 25초 기다리거나 혼자 함선에서 깨어나야 해서 차이를 크게 뒀어요. 대신 부축하려면 외계인 옆까지 가야 하니까 위험은 그대로예요. 실제 플레이 데이터 보고 1.2초 정도로 올릴지 결정하죠.
- **하은:** 모든 걸 다 모아서 이륙하는데 엔딩이 텍스트 한 장이에요. 2시간 고생한 보상이 너무 약해요.
- **은겸:** 동의해요. 다음 회의 안건으로.

**결정 사항**
- 의무병 부축 0.8초 유지, 실제 플레이 후 재검토 (📋)
- 이륙 연출 필요 → 6차 회의에서 다룸

## 6차 회의 — 엔딩 연출 & GitHub 출시 준비

**안건:** 이륙 컷신, 배포 체크리스트

- **하은:** 엔딩 흐름: 전원 탑승 → 화면 전환 → **함선 밖 카메라에서 아르카디아 7호가 엔진 불을 뿜으며 떠오름** → 하얗게 페이드 → 결과 화면(생존 대원, 플레이 시간, 쓰러진 횟수, 오리온-3 로그 수).
- **은겸:** 10초짜리 컷신으로 넣었어요. 함선이 기울면서 가속하고, 아래로 굉음 효과음. ✅
- **하나:** 오리온-3 로그 5개 다 모으면 엔딩 문장이 바뀌는 거 좋아요. 그거 때문에 2회차 할 것 같아요.
- **삼식:** 친구 초대할 때 "파일로 열면 링크 안 됨"을 모르는 사람 많을 거예요.
- **은겸:** 로비에 경고 문구가 이미 떠요. 그리고 리스크 하나 공유할게요. 지금은 **PeerJS 공개 중계 서버**에 의존해서, 학교나 회사 와이파이에서는 막힐 수 있어요. 출시는 이대로 하고, 문제가 생기면 그때 자체 서버를 검토해요.
- **두리:** 방장이 튕기면 다 끝나는 것도 문제예요.
- **은겸:** 방장 넘겨받기(host migration)는 큰 작업이라 다음 스프린트로. 지금은 30초마다 자동 저장되니까, 방장이 "이어하기"로 방을 다시 열면 돼요.

**결정 사항**
- ✅ 이륙 컷신 → 결과 화면
- ✅ 타이틀 화면에 역할 선택 카드, 조작 안내에 Q 핑 추가
- GitHub Pages 배포 절차는 README 기준으로 진행

## 7차 회의 — 회고 & 다음 스프린트 백로그

**잘된 점**
- **하은:** "검색해서 대체 재료를 찾는다"는 핵심 콘셉트가 끝까지 살아 있어요.
- **삼식:** 동시 수행 미션(레버·중계기·핵 추출·점화)이 멀티의 존재 이유가 됐어요.
- **두리:** 첫 밤이 대기 시간에서 이벤트가 됐어요.

**아쉬운 점**
- **은겸:** 이번 회의 피드백은 전부 가상 시나리오예요. 진짜 사람이 2시간을 처음부터 끝까지 해본 기록이 아직 없어요.
- **하나:** 효과음이 전부 합성음이라 분위기를 다 못 살려요.

## 8차 회의 — 백로그 2·3번 구현 리뷰: 포자 폭풍 & 울보

**안건:** 7차에서 정한 백로그 2번(포자 폭풍), 3번(울보 개체) 설계 확정과 구현 확인

**포자 폭풍**
- **하은:** 폭풍이 그냥 "시야 나쁨"이면 짜증만 나요. 위험과 함께 **기회**를 줘야 해요. 그래서 폭풍의 냉기로 공명 결정이 식어서, **폭풍 중엔 낮에도 결정을 캘 수 있게** 했어요.
- **두리:** 오, 그럼 미션 9(냉각 코일)에서 밤까지 기다리거나 다 같이 자러 갈 필요 없이 폭풍을 노리면 되네요. 루트가 하나 더 생겼어요.
- **은겸:** 규칙은 이래요. 미션 4(흩어진 부품)부터 낮(06:00~17:30)에만 와요. 첫 폭풍은 미션 시작 후 2.5~4.5분, 그 뒤로는 5.5~8.5분 간격이에요. 15초 경고 → 70초 지속, 처음과 끝 8초는 서서히 짙어지고 옅어져요. 폭풍 중엔 외계 생물이 (대원 수+1)마리 깨어나고, 끝나면 다시 땅속으로 돌아가요.
- **하나:** 화면이 누런 녹색으로 덮이고 포자가 옆으로 날리는 게 분위기 있어요. 경고음 낮게 웅— 하는 것도 좋고요.
- **삼식:** 폭풍 중에 친구 어디 있는지 모르겠던데, 핑이 빛 기둥이라 안개 뚫고 보여서 다행이에요.

**울보**
- **하은:** 기존 개체는 "빛에 끌림"이라 손전등을 끄는 게 정답이었어요. 울보는 반대로 **손전등을 정면으로 비추면 겁먹고 도망가요.** 이제 손전등을 켤지 말지가 상황 판단이 돼요.
- **은겸:** 울보는 직접 공격하지 않아요. 30m 안에서 대원을 발견하면 1.8초 동안 멈춰서 비명을 지르고, **70m 안의 모든 개체가 그 대원을 12초 동안 추적**해요. 재사용 대기는 14초, 평소엔 16m 거리를 유지하며 맴돌아요. 미션 7(대체 연료)부터 밤·폭풍에 섞여 나오고, 솔로는 최대 1마리, 멀티는 2마리예요.
- **두리:** 그럼 정찰병이 울보 담당이네요. 손전등 켜고 울보 쫓아내는 동안 나머지는 꺼고 숨어 있고.
- **하나:** 창백한 몸에 목의 노란 울음주머니가 부풀면서 우는 게 진짜 소름이에요. 처음 나왔을 때 MIRA가 약점까지 알려줘서 좋았어요.
- **삼식:** 비명 들리면 화면 가운데 "울보의 비명!" 경고가 떠서, 소리를 꺼놓고 해도 알 수 있어요.
- **은겸:** 검색 백과사전에도 "폭풍", "울보" 항목을 추가했어요.

**결정 사항**
- ✅ 포자 폭풍 이벤트 (위험: 시야·주간 출현 / 기회: 주간 결정 채굴)
- ✅ 울보 개체 (비명으로 무리 호출, 손전등에 약함)
- 📋 다음: 실제 사람 플레이 테스트로 폭풍 빈도·울보 출현율 조정 (지금 값은 추정치)

## 9차 회의 — 그래픽 업그레이드 & 모바일 UI (가벼움 유지)

**참석자:** 은겸 (개발 7년차, 대규모 게임 다수) · 하은 (게임 그래픽 8년차) · 현빈 (그래픽 디자이너 5년차) · 민석 (우주 SF 영화감독 10년차)

**안건:** "그래픽은 훨씬 좋게, 그런데 옛날 아이폰에서도 돌아가게. 주 플랫폼은 모바일."

### 1. 목표 설정 — 무엇이 "무거움"인가

- **은겸:** 모바일 웹에서 프레임을 잡아먹는 건 대개 세 가지예요. ① 픽셀 수(해상도), ② 물체마다 계산하는 빛 개수, ③ 그림자 맵. 폴리곤 수는 생각보다 덜 중요해요. 지금 빌드는 폰에서도 광원이 **18개**라, 화면의 모든 픽셀이 빛 18개를 계산하고 있어요.
- **하은:** 그러면 "예쁜 효과"를 실제 계산 대신 **그려 넣은 착시**로 바꾸죠. 빛 번짐(블룸)은 후처리 대신 빛나는 점 스프라이트, 그림자는 발밑 동그란 그림자.
- **민석:** 영화 쪽에서도 다 그렇게 해요. 관객이 기억하는 건 **실루엣·색 대비·빛의 방향**이지 계산 정확도가 아니에요. 녹턴의 정체성은 "보랏빛 낮, 생물발광 밤". 이 대비만 확실하면 돼요.

**결정:** 품질 3단계 + 자동 선택 (폰 기본 '낮음', PC 기본 '높음')

| 항목 | 낮음 (옛날 폰) | 보통 | 높음 (PC) |
|------|------|------|------|
| 재질 | Lambert (가벼움) | Lambert | Standard (물리 기반) |
| 실제 광원 | 5개 (나머지는 빛 번짐 스프라이트) | 전부 | 전부 |
| 그림자 | 발밑 그림자 | 발밑 그림자 | 그림자 맵 |
| 풀 / 장식 밀도 | 700 / 60% | 1,600 / 85% | 3,200 / 100% |
| 하늘 성운·오로라 | 단순 띠 | ✅ | ✅ |
| 해상도 배율 | 0.55~1.0 자동 | 0.7~1.4 자동 | 0.85~1.75 자동 |

- **은겸:** 해상도는 고정하지 말고 **1초마다 FPS를 재서 자동으로 오르내리게** 해요. 아이폰 8이든 최신 폰이든 같은 코드로 맞춰져요. 최저로 낮춰도 버벅이면 "품질을 낮춰 보세요" 안내를 한 번 띄우고요.
- **현빈:** 아이폰 Safari는 메모리 정보를 안 알려줘서 기기 판별이 안 돼요. 그래서 폰은 무조건 '낮음'에서 시작하고 여유가 있으면 해상도만 올리는 게 안전해요.

### 2. 그래픽 — 비용 대비 효과 큰 것만

- **민석:** 첫 장면은 무조건 **하늘**이에요. 밤하늘에 은하수 띠와 성운, 초록 오로라가 흐르면 "외계 행성"이라는 게 1초 만에 전달돼요.
- **은겸:** 하늘은 원래 셰이더라 노이즈 몇 줄 추가하는 비용뿐이에요. 다만 화면 대부분을 덮으니 '낮음'에선 노이즈 없이 단순한 띠만 그려요.
- **하은:** 밤의 버섯 숲·결정·나무 전구에 **빛 번짐 점**을 붙여요. 수백 개를 점 하나짜리 그리기 1번으로 처리하고, 안개 거리에 따라 자연스럽게 사라지게.
- **현빈:** 우주선이 밋밋한 흰 원통이었어요. **패널 라인·리벳·"ARCADIA · 7" 표기·추락 그을음**을 캔버스로 그려 텍스처로 입히고, 동체 옆에 창문 불빛 줄을 넣죠. 전력이 복구되면 켜지게 — 진행이 눈에 보여요.
- **하은:** 지형은 경사면을 바위색으로, 넓은 얼룩 무늬로 청록·자주 색을 섞어요. 시작할 때 한 번 계산이라 실행 중 비용은 0이에요.
- **민석:** 풀이 **바람에 흔들리면** 화면이 살아 있어요. 포자 폭풍 때는 더 세게.
- **은겸:** 그건 정점 셰이더에서 처리해서 CPU 비용 0이에요. 호수에도 천천히 흐르는 잔물결 텍스처를 넣고요.
- **현빈:** 다른 대원은 **등에 팀 색 표시등**을 달아요. 밤에 누가 누군지 바로 보여요. 손전등을 켜면 **빛 원뿔**이 보이게 — 실제 광원이 없는 '낮음'에서도 "저기서 비추고 있구나"를 알 수 있어요.
- **민석:** 연출 쪽은 두 가지만요. **피격·울보 비명·점화 때 카메라 흔들림**, 그리고 깨어날 때와 엔딩에 **위아래 검은 띠(레터박스)**. 둘 다 비용이 거의 없어요.

### 3. 모바일 UI — "엄지 두 개로 끝나야 한다"

- **현빈:** 지금 E 버튼은 뭘 하는 버튼인지 몰라요. **바라보는 대상에 따라 아이콘과 글자가 바뀌는 행동 버튼**으로 바꾸죠. 🌿 채집, ⛏️ 채굴, 📡 튜닝, 👇 꾹 누르기… 길게 눌러야 하는 건 버튼 둘레에 진행 링이 차오르고, 대상 이름은 버튼 옆 말풍선에.
- **은겸:** 그럼 화면 가운데 안내 문구는 폰에선 숨겨요. 시선을 가리거든요.
- **하은:** 미션 카드도 폰에선 **지금 할 일 한 줄**만 보여주고, 누르면 펼쳐지게.
- **현빈:** 버튼은 애플 기준 최소 44pt. 큰 손·작은 손을 위해 **버튼 크기 설정(작게/보통/크게)**, 그리고 **진동 피드백** (줍기·목표 달성·피격). 아이폰 Safari는 진동을 지원하지 않아서 안드로이드에서만 동작해요.
- **은겸:** 아이폰은 입력칸 글자가 16px보다 작으면 화면을 확대해 버려요. 모든 입력칸을 16px로.
- **민석:** 메시지가 화면 아래를 덮어서 조이스틱을 가렸어요. **위쪽 가운데에 최근 2개만**.
- **현빈:** 끝까지 밀면 자동 달리기가 되는데, 그걸 몰라요. 달릴 때 조이스틱이 빛나고 "달리기" 표시가 뜨게.

### 결과 (측정)

같은 장면(밤, 우주선 앞 / 버섯 숲), 같은 해상도(844×390, 배율 1)에서 이 PC로 측정:

| | 이전 폰 모드 | **새 '낮음'** | 새 '높음' |
|---|---|---|---|
| 한 프레임 처리 시간 | 11.0 / 11.6ms | **5.0 / 3.8ms** | 32.9 / 26.4ms |
| 그리기 호출 (우주선 앞) | 419 | **227** | 654 |
| 광원 수 | 18 | **5** | 18 |

- **은겸:** 폰용 '낮음'은 예전보다 **약 2.5배 가벼워졌는데** 화면은 더 풍성해졌어요. '높음'은 그림자 맵 때문에 그리기가 두 번이라 무거워요. 성능이 낮은 PC에서 버벅이면 안내가 떠요.
- **하은:** 단, 실제 옛날 아이폰에서 직접 돌려 본 건 아니에요. 다음 회의 전에 실제 기기(아이폰 8 / SE 2세대급)로 FPS를 재야 해요.
