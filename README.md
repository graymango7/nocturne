# NOCTURNE: 불시착

인류 이주선 **아르카디아 7호**가 새 정착지 케플러-442b로 가던 중 미확인 행성 **KX-9 "녹턴"**에 불시착했다.
흩어진 부품을 모으고, 완전히 부서진 부품은 휴대폰으로 검색해서 이 행성의 재료로 대신 만들어 탈출하는 **1~4인 협동 생존 게임**.

- 브라우저에서 바로 실행 (설치 없음), Three.js 3D
- **링크 하나로 멀티플레이**: 서버 없이 WebRTC(PeerJS) P2P 연결
- 손이 보이는 1인칭 시점 (V 키로 3인칭 전환)
- 역할 선택: 🏃 정찰병 / 🔧 엔지니어 / ⛑️ 의무병
- 핑(Q/우클릭)으로 음성 없이도 위치 공유
- **모바일(폰) 지원**: 로블록스식 터치 조작, PC와 폰이 같은 방에서 함께 플레이 가능
- 30초마다 자동 저장 (방장/솔로 브라우저에 저장, "이어하기"로 계속)

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일(`index.html`, `style.css`, `js/`)을 올린다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)`로 지정한다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 주소가 생긴다.
4. 게임에서 **방 만들기** → 나오는 초대 링크(`...?room=ABCDE`)를 친구에게 보내면 끝.

> 파일을 더블클릭(`file://`)으로 열면 혼자 하기는 되지만 친구 초대 링크는 동작하지 않는다. 반드시 GitHub Pages 같은 웹 주소로 열 것.

**돌발 이벤트·위협**
- ☣ **포자 폭풍** (미션 4부터, 낮에 가끔 35초): 시야가 막히고 낮에도 외계 생물이 깨어나지만, 폭풍 중엔 밤에만 캘 수 있는 결정을 캘 수 있다.
- 📦 **보급 캡슐** (첫 밤부터, 밤마다 최대 2번): 하늘에서 떨어진 캡슐을 열면 조명탄과 자원을 얻는다. 여는 소리에 주변 개체가 몰려온다.
- 🌼 **월광화 → 🏮 휴대용 UV 랜턴**: 밤에만 피는 꽃 2송이 + 섬유 2개로 제작, [G]로 어디든 설치하면 60초 동안 반경 9m가 안전 구역.
- 😱 **울보** (미션 7부터): 공격하지 않는 대신 비명으로 70m 안의 개체를 전부 불러 모은다. 다른 개체와 반대로 손전등을 정면으로 비추면 달아난다.

추가 요소: 오리온-3 탐사대의 데이터 로그 5개(숨겨진 이야기, 모으면 엔딩이 달라짐), 쓰러진 동료 부축, 낮/밤 주기, 채팅.
혼자 할 때는 동시 수행 미션의 제한 시간이 길어져서 혼자서도 끝까지 갈 수 있다.

### 모바일 (로블록스식)

- 왼쪽 화면을 엄지로 누르면 그 자리에 **썸스틱** (끝까지 밀면 달리기)
- 오른쪽 빈 화면 **드래그 = 카메라 회전**
- 오른쪽 아래 큰 **⤒ 점프**, **E** 줍기/사용 — 화면 가운데 뜨는 안내 버튼을 눌러도 됨 (길게 누르기)
- 🧎 웅크리기(켜기/끄기) · 🔦 손전등 · 🧨 조명탄 · 📍 핑 · 🏮 랜턴 · 오른쪽 위 📱 휴대폰 · 💬 채팅 · 🎥 1인칭/3인칭 · ☰ 일시정지
- **가로 화면** 전용. 시작하면 전체화면으로 전환을 시도한다 (아이폰 Safari는 전체화면 미지원).
- 폰에서는 그림자를 끄고 해상도를 낮춰 프레임을 확보한다.
- PC에서 터치 화면을 미리 보려면 주소 끝에 `?touch=1`을 붙인다.

## 알려진 한계

- 방장이 나가면 방이 끝난다 (방장 브라우저가 서버 역할). 방장이 "이어하기"로 다시 열고 새 링크를 보내면 이어서 할 수 있다.
- PeerJS 공개 중계 서버를 사용하므로, 일부 회사/학교 네트워크에서는 연결이 막힐 수 있다.
- 폰을 **LTE/5G 데이터**로 쓸 때는 통신사 네트워크 구조 때문에 P2P 연결이 실패할 수 있다 (중계용 TURN 서버가 없음). 같은 와이파이에서 하면 가장 안정적이다.
